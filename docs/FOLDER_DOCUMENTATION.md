# Folder Documentation

## Root Directory

### `jarvis_v2.py` — Main Entry Point
The primary voice assistant loop. Initializes all subsystems, loads ASR models, and runs the wake/listen/plan/execute/speak cycle. See [Architecture Guide](../ARCHITECTURE.md) for the complete flow.

### `jarvis.py` — Minimal CLI Version
Simple text-based interface using Ollama directly. No voice, no plugins, no task execution. Useful as a minimal reference implementation.

### `voice_jarvis.py` — Voice-Only Prototype
Basic voice loop with Whisper + Piper + Ollama chat. No task execution subsystem. Predecessor to `jarvis_v2.py`.

### `planner.py` — Intent Planner
Maps natural language to structured action plans. Hybrid regex + LLM approach. Contains 70+ regex patterns in `_FAST_PATH_TRIGGERS` and the LLM fallback planner. Also handles multi-step splitting and pronoun resolution.

### `task_executor.py` — Task Executor
Dispatches action plans to handler functions. Contains 50+ handler implementations and the `execute_plan()` entry point. Maintains execution context and metrics.

### `ui_core.py` — UI Automation
Low-level Windows UI automation using ctypes (Win32), pywinauto, and PyAutoGUI. Contains `WindowManager`, `UIAutomator`, `ElementLocator`, and `StrictWindowValidator`. Provides the `SUPPORTED_APPS` profile dictionary.

### `search_agent.py` — In-App Search
Prioritized search engine with fallback chain: keyboard shortcuts → accessibility → OCR → vision. Each search verifies window focus and validates the target window.

### `app_launcher.py` — Application Launcher
Universal Windows app launcher. Discovers apps from Start Menu, Registry, UWP, and common install locations. Provides verified launch with process/window/UI readiness checks.

### `settings_manager.py` — Configuration Manager
Thread-safe configuration loader. Reads `config.json`, deep-merges with defaults, and provides dot-notation access. Used by all modules for path, model, and voice configuration.

### `memory.py` — Legacy Memory Store
Simple JSON-backed persistent fact store. Minimal API: `load()` / `save()`. Maintained for backward compatibility.

### `memory_v2.py` — Multi-Tier Memory System
Advanced memory architecture with five tiers: short-term, long-term, project, conversation, and preference. Supports importance scoring, TTL, semantic search (optional FAISS), and automatic backup.

### `session_memory.py` — Session Context Tracker
In-memory session state for pronoun resolution and context awareness. Tracks current app, window, folder, file, and recent actions.

### `file_manager.py` — Sandboxed File Operations
File and folder operations sandboxed to safe directories (HOME, CWD, TEMP). Blocks system directories. Supports create, read, write, append, delete, rename, move, copy, and search.

### `pc_control.py` — System Control
Wraps Windows system commands: lock, sleep, logoff, shutdown, restart. Also opens shell folders (Downloads, Documents, Desktop) and admin tools (Task Manager, Control Panel, Registry Editor). Destructive ops require confirmation.

### `clipboard_tools.py` — Clipboard Access
Tkinter-backed clipboard read, write, clear, and LLM-based summarization. Uses a process-lifetime Tk root for stability.

### `calendar_engine.py` — Calendar Events
Generates `.ics` calendar files. Parses natural language dates/times. Opens files with the default calendar handler (Outlook, Windows Calendar).

### `reminders.py` — Reminder Engine
Persistent reminder system with JSON storage. Natural language time parsing ("tomorrow 4 pm", "in 30 minutes"). Background thread checks every 20 seconds.

### `email_actions.py` — Email Integration
Opens Gmail compose with pre-filled recipient, subject, and body. Never auto-sends. Includes a resolvable address book.

### `whatsapp_actions.py` — WhatsApp Integration
Opens WhatsApp Web with pre-filled contact and message. Never auto-sends. Includes a contact book with E.164 phone numbers.

### `code_generator.py` — Code Generation
Generates code via Ollama. Supports multiple languages. Includes optional file write with OS open. Uses ThreadPoolExecutor with 45-second timeout.

### `speech_correction.py` — ASR Post-Processing
Corrects common Whisper transcription errors using a configurable dictionary. Also corrects common mispronunciations and stutters.

### `diagnostics.py` — Environment Diagnostics
Comprehensive startup health check. Tests library availability, Win32 API, window manager, accessibility, search engine, UWP, and automation.

### `config.json` — User Configuration
Central configuration file. Defines paths, model names, voice settings, and system prompt. Loaded by `SettingsManager`.

### `apps.json` — Installed Apps Cache
Cached list of installed Windows applications with AppUserModelIDs. Generated by `app_launcher.py` or `generate_apps.py`.

### `reminders.json` — Reminder Storage
Persistent storage for the reminder engine. Auto-created and managed by `reminders.py`.

### `memory.json` — Legacy Memory Storage
Persistent fact storage for `memory.py` and backward compatibility layer in `memory_v2.py`.

### `disabled_plugins.json` — Plugin Disable State
Persisted list of disabled plugin names. Managed by `PluginManager`.

## Subdirectories

### `plugins/` — Plugin System
Contains the plugin architecture and installed plugins.

| File | Description |
|------|-------------|
| `__init__.py` | `Plugin` base class, `PluginManager`, `PluginMetadata` |
| `weather.py` | Example weather plugin (demonstrates tool plugin) |
| `system_monitor.py` | Example system monitor plugin (demonstrates handler + command + hook) |
| `agents/` | Agent orchestration system |
| `agents/__init__.py` | `EventBus`, `MessageQueue`, `BaseAgent`, `AgentOrchestrator` |

### `plugins/agents/` — Agent Orchestration
Event-driven multi-agent system for background processing and task decomposition. Agents communicate via typed events through the EventBus and MessageQueue.

### `Screenshots/` — Captured Screenshots
Stores screenshots captured by `_capture_screen()` in `task_executor.py`. Used by the screen awareness feature.

### `CalendarEvents/` — ICS Calendar Files
Stores `.ics` files generated by `calendar_engine.py`. Files are opened with the OS default calendar handler.

### `Backups/` — Memory Backups
Automatic backups of long-term memory, created by `LongTermMemory._save()`. Backup interval: 5 minutes.

### `docs/` — Documentation
This directory. Contains all project documentation files.

### `venv/` — Python Virtual Environment
Standard Python virtual environment (not tracked in version control).

### `__pycache__/` — Python Bytecode Cache
Auto-generated by Python (not tracked).

### `.pytest_cache/` — Pytest Cache
Auto-generated by pytest (not tracked).
